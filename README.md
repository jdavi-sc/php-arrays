## 🎯 Objetivo

Este repositório tem como objetivo centralizar, documentar e exemplificar os principais conceitos sobre a manipulação de arrays na linguagem PHP. O projeto foi estruturado de forma prática e modular, servindo como material de referência rápida para futuras consultas sobre sintaxes, particularidades e funções nativas de arrays.

> 🎓 **Nota Acadêmica:**  
> Projeto desenvolvido para fins de estudo e fixação prática de conteúdo, com base nas atividades e matérias da **Universidade Estácio de Sá**.

## 🛠️ Tecnologias Utilizadas

- **[Git](https://git-scm.com/)** — Controle e versionamento do código.

## 📂 Estrutura do Projeto

O repositório está organizado em pastas sequenciais por tópicos:

```text
php-arrays/
├── 01-arrays-numericos/
│   └── arrays_numericos.php         # Declarações, atribuições, ordenação e iteração
├── 02-arrays-associativos/
│   └── arrays_associativos.php      # Chaves nomeadas (chave => valor) e manipulações
├── 03-arrays-mistos/
│   └── arrays_mistos.php            # Junção de índices numéricos e chaves associativas
├── 04-arrays-multidimensionais/
│   └── arrays_multidimensionais.php # Matrizes e arrays em múltiplas dimensões
└── 05-funcoes-nativas/
    └── funcoes_nativas.php          # Funções nativas essenciais (count, splice, search, etc.)
```

---

## 🚀 Como Executar

Com o **PHP** instalado no ambiente, você pode executar qualquer um dos arquivos diretamente pelo terminal:

```bash
# 1. Arrays Numéricos
php 01-arrays-numericos/arrays_numericos.php

# 2. Arrays Associativos
php 02-arrays-associativos/arrays_associativos.php

# 3. Arrays Mistos
php 03-arrays-mistos/arrays_mistos.php

# 4. Arrays Multidimensionais
php 04-arrays-multidimensionais/arrays_multidimensionais.php

# 5. Funções Nativas
php 05-funcoes-nativas/funcoes_nativas.php
```
